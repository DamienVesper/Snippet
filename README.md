## Prerequisites
 * [bun](https://bun.sh)
 * [Node.js](https://nodejs.org)
 * [PostgreSQL](http://postgresql.org)

## Installation
In the root directory, run the following command to install packages for all directories and subdirectories.
```sh
bun ci
```
